Dynamic dispatch

At runtime, the halting problem is a tautology!!!

Trampolines: check dynamic dispatch and re-enter correctness

@include std.core

def state(tag func, u64 n)
    return @args
def ping(u64 n)
    print("ping")
    return :pong.state(n)
def pong(u64 n)
    print("pong")
    return :ping.state(n-1)

service main()
    @mut T = ping(4) // mutable state
    while T.n.bool()
        T = @dynamic(ping,pong) T() //call by tag name

No proof = error

Robust handling (e.g., no leaks, no use after free)

@include std.core // includes add(u64 a, u64 b)

def state(tag func, u64 a)
    return @args

service test(state T, u64 b)
    return @dynamic(add) T(b)

service main()
    result = :unknown.State(1).test(2) // should have used :add
    if result.err.bool().not() // error handling service return
        print("Something went wrong")
    print("Bye!")
